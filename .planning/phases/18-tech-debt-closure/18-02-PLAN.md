<objective>
Close DEBT-05: the client and server each decide "this cart is digital-only" from a different
signal, and today they cannot disagree — but nothing in either file says so. Make the
equivalence explicit in both files, pointing at the test that already proves it, so an edit to
either predicate's semantics is flagged to a human instead of drifting silently.

Purpose: D-05 records the deliberate decision that this is *documented equivalence pinned by a
test*, not literal code sharing. Plumbing `fulfillment_type` onto the client `CartItem` is a
materially bigger change than tech-debt closure and is a Deferred Idea. This plan makes the
existing pin discoverable and adds the one assertion that catches a silent removal.

Output: two cross-referencing doc comments and a hardened invariant test.
</objective>

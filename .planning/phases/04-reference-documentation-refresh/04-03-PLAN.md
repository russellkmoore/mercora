## Shell rules for every command in this plan

Confirmed live in `04-RESEARCH.md` "Common Pitfalls" #2: a shell hook intercepts bare `grep` and `find` here and returns wrong counts, and a bare `find` returns a garbled multi-file summary instead of paths.

- Absolute paths in every gate: `/usr/bin/grep`, `/usr/bin/sed`, `/usr/bin/wc`, `/usr/bin/basename`, `/bin/ls`.
- Never `diff <(...) <(...)` — a shell function shadows `diff`.
- `/usr/bin/grep -c` prints `0` and exits 1 on a clean file; `test "$(...)" = "0"` is the correct idiom. No `|| echo 0` fallbacks — they turn a wrong path into a passing gate.

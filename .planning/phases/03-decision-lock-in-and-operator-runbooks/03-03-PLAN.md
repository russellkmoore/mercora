<objective>
Remove the dead checkout-session webhook branch and pin the behaviour that replaces it.

Purpose: the branch calls a handler whose body is comments only and sets the dispatch outcome to
`ignored`, which is exactly what the `default` branch already does. Removing it is behaviour-neutral and
completes RUN-02's code half, so the route stops advertising an event that does no work. A regression
test then pins the contract an unhandled event type must keep: HTTP 200, ledger outcome `ignored`, no
finalizer call.

Output: a smaller dispatch switch, a header comment that matches it, and one new test file.
</objective>

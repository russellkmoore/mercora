<objective>
Close the last two of SHOP-05's four surfaces: the order confirmation modal and the account order detail page.

Purpose: a shopper who has just paid should see who each card is going to before they leave the page, and should be able to find it again later in order history. Both surfaces read data that already exists — the cart snapshot on one, the persisted gift_card field on the other — so this is rendering work, not plumbing.

Output: an optional items list on the confirmation modal; a gift-card block under each gift-card item on the account order detail page, proving the shared component crosses the Server Component boundary; two new source-contract test files.
</objective>

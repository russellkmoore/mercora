<objective>
Prove the whole Phase 12 production tool chain end to end before anything writes: one Node process opens production `DB`, `MEDIA`, `VECTORIZE` and `AI` through `getPlatformProxy` against a scratch copy of `wrangler.jsonc`, and reads real data from each. This is the tracer slice — every later plan in this phase rides on either this mechanism or the `wrangler` CLI it validates.

The load-bearing risk it retires (12-RESEARCH.md Pitfall 1, verified against the installed wrangler 4.129.0 source): `remoteBindings: true` alone does NOT reach production for D1, R2 or Vectorize. Without a per-binding remote flag those three silently fall back to an empty local Miniflare simulator, and a re-index would report success while indexing nothing. Only `AI` is unconditionally remote, which is why Phase 9's image script worked with no extra config and this one will not.

Purpose: fail fast, cheaply, and read-only, if wrangler auth, remote bindings, or the scratch-config trick are broken — before a single production write in 12-02..12-05.
Output: a working scratch harness whose shape the SUMMARY records, plus four measured production numbers later plans assert against.

Per D-11 this phase ships no template or component changes; planning ran with `--skip-ui`.
</objective>

Add a `main()` guard so running the file directly executes four read probes and prints their results — nothing else. Read probes, in order:
1. `await env.DB.prepare('SELECT COUNT(*) AS n FROM products').first()` — production currently holds 33 product rows (measured read-only at planning time, 2026-09-09).

It reads no `.dev.vars`, no `.env.local`, and no secret name of any kind. It calls `dispose()` in a `finally` block. Keep every write-shaped call out of the source entirely rather than guarding it at run time, so the source grep in the acceptance criteria is a real gate.

Print a single summary line per probe and exit 0 only when all four pass; exit 1 with the failing probe named otherwise. A zero count on probe 1, 2 or 3 means the local-simulator fallback happened and must be treated as failure, not as an empty index.

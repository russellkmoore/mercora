<objective>
Make the two operator-facing docs say what the code now does.

Today `docs/runtime-configuration.md` says acquisition "requires reconciliation enabled" and
`docs/DEPLOYMENT_SETUP.md` §9 says to leave reconciliation on "for as long as any balance or
reservation exists" — advice, not a rule. After this phase it is a rule the runtime enforces, and
the docs need the four-state table, the outstanding-balance behaviour, and the rollback recipe in
sell/honor language (D-12).

The second half of this plan is the part that keeps it true: a source-contract test that reads
both docs and checks their claims against the actual capability code and honor-guard constants.

Purpose: GCF-05, plus the documentation half of GCF-02.
Output: two rewritten doc sections and a test that goes red when they drift.
</objective>

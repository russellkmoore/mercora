## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository -> production | a push to `main` applies a migration and replaces the running Worker |
| anonymous internet -> deployed admin surface | the first thing worth checking after any admin feature ships |
| documentation -> operator action | a doc that understates what a switch does is how a switch gets turned on carelessly |

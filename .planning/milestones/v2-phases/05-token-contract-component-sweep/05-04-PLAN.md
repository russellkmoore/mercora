<objective>
Rewrite the nineteen shadcn primitives to the token contract, replacing a colour vocabulary
this codebase never defined.

Purpose: these primitives reference `accent`, `muted`, `destructive`, `secondary`, `card`,
`popover`, `input`, `background`, and `primary-foreground` — CSS variables that exist in
upstream shadcn but were never declared here. Today they render nothing, which is why hover and
focus states across dropdowns, the navigation menu, select, dialogs, table rows, and buttons are
invisible. Rewriting them is the single highest-leverage chunk in the sweep: nineteen files feed
every page in the storefront.

Output: every `components/ui/*` file scan-clean, and a screenshot set that deliberately captures
the interaction states which are about to become visible for the first time (D-17).
</objective>

<objective>
Convert the two light drawers from hardcoded light values to the five inverse tokens, keeping
their light-on-dark polarity exactly as it is.

Purpose: this is the only chunk in the phase where the inverse token set applies, and the only
one where a wrong token choice flips a surface from light to dark. D-05 made the light drawers
a deliberate design decision with five dedicated tokens behind it so a future light preset can
flip them to dark panels; D-06 made the inverse set mirror the main set for exactly that reason.
Those five tokens have no other consumer in the storefront — if this chunk gets them wrong, they
are wrong everywhere.

Output: four drawer files scan-clean, both hardcoded light hexes gone, and screenshots of both
open drawer states proving the polarity held.
</objective>

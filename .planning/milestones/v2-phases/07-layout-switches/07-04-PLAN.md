Build the island as a copy of the theme grid's structure, not as a new invention. Same file shape:
the exported extraction helper at the top, the exported roving-index helper beside it, the pure
content component, then the stateful wrapper.

The three groups are driven by a single local table describing each switch — its group label, its
setting key, its enum array, its default, and its per-member option list of icon plus label. Driving
all three groups from one table is what keeps the roving-index and ARIA wiring written once and
applied three times instead of copy-pasted three times, and it is what makes a future fourth switch
a data change.

Keyboard behaviour is scoped per group: arrow keys move within the group that received the event and
never jump between groups, space and enter select, and focus follows selection. Copy the theme
grid's handler and give each group its own option-id prefix so the focus lookup cannot collide.

The extraction helper takes the settings response rows and returns all three selections. Per switch:
find the row by its key, parse its stored value, accept it only if it is a string that is a member of
that switch's own enum array, and fall back to that switch's default for anything else. Test
membership against the array, never by indexing an object — the same allow-list posture the server
resolver uses, applied client-side so the highlighted option can never claim a layout the storefront
would not actually render.

Save posts one request with three updates, one per key, under the appearance category, to the
existing endpoint. Do not add an API route and do not add a second write path — the existing guard on
that endpoint is the authorisation control for this feature, and a new route would be a second door.
Re-check each pending value against its own enum before posting. On success, set the saved values
from the endpoint's own response body rather than from the pending state, and clear the pending
values; on failure, show the error toast and keep every pending value so a retry is one click.

The fetch on mount reads the appearance category and is this island's own — the theme grid also

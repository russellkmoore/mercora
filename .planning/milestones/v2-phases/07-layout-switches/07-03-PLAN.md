<objective>
Make the product gallery's position a stored, server-chosen decision: extract today's two-column
gallery verbatim into a named client component, add the full-width variant beside it, and let the
product page choose between them by passing a typed enum member across the server-to-client boundary.

Purpose: LAYOUT-03. This is the one place in the phase where resolution happens on the server and
rendering happens on the client, so it is the one place where the anti-genericity rule is easiest to
break by accident — a prop genuinely has to cross, and it has to cross typed and named for its own
switch.

Output: two gallery components, a shared media URL helper moved verbatim, a product display that
dispatches through a typed map, a rewired product page, and a live probe showing the served product
page change when the stored gallery value changes.
</objective>

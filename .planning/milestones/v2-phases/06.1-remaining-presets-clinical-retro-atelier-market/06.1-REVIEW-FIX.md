## Fixed Issues

### CR-01: `font-display` wiring exposes a missing-weight regression on the Luxe theme

**Files modified:** `app/layout.tsx`
**Commit:** 0d443d9
**Applied fix:** Widened `cormorantGaramond`'s `weight` array from `["400","500"]` to `["400","500","600","700"]`, matching the pattern already used for `orbitron`/`fraunces`/`nunito` in this phase. Google's Cormorant Garamond tops out at 700, so `font-extrabold` (800) requests resolve to 700 rather than a true 800 — an acceptable nearest-match given `font-synthesis: none`, versus the previous 500 ceiling.

### WR-01: `select.tsx`'s highlighted-row fix was overridden back to invisible at `ProductDisplay.tsx`'s variant selector

**Files modified:** `app/product/[slug]/ProductDisplay.tsx`
**Commit:** 24e8fb2
**Applied fix:** Removed the call site's own `hover:bg-surface-elevated focus:bg-surface-elevated` classes from the variant `SelectItem`, leaving only `className="text-foreground"`. `twMerge` was keeping this call site's `focus:bg-surface-elevated` over the base component's fixed `focus:bg-primary/10` (className is merged last in `cn()`), reintroducing the invisible-highlight bug. Grepped all other `SelectItem` callers in the repo — no other call site passes a conflicting `focus:bg-*` class, so no further changes were needed.

### WR-02: No automated test for the `next/font` variable-class / body-font-family wiring

**Files modified:** `tests/unit/app/layout-font-wiring-source.test.ts` (new file)
**Commit:** 9812564
**Applied fix:** Added a source-contract test (RootLayout can't be rendered directly in this project's vitest — async server component wrapping ClerkProvider and a D1 theme lookup, and there's no jsdom/@testing-library dependency) asserting: (1) all six next/font variable class tokens are present on both `<html>` and `<body>` in `app/layout.tsx`, and (2) `app/globals.css`'s `body` rule declares `font-family: var(--store-font-sans)` while the `html` rule never hard-codes a literal font stack. Ran the new test file in isolation (4/4 passing) before the full suite run.

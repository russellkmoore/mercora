# Phase 8.1 Plan 05: One Image Resolver, Required Gallery Prop Summary

**Retired the duplicated `getMediaUrl` gallery helper in favor of `resolveProductImageSrc`, accepted the one documented leading-slash output change, and made `ProductDisplay`'s `productGallery` prop required with zero runtime change.**

## Accomplishments

- One image-URL resolver (`lib/utils/product-image.ts`'s `resolveProductImageSrc`) now serves both product gallery variants; `components/layout/product/gallery-media-url.ts` is deleted and no reference to it survives anywhere in `app/`, `components/`, `lib/`, or `tests/`.
- The pre-extraction parity oracle (`product-gallery-left-preextraction.txt`) was never touched — the parity test now declares four named substitutions (the two original closure-to-prop lines plus the two resolver-swap `src=` lines), and every other recorded line still matches the component source character for character.
- The one accepted output change (D-11) — a bare relative path gains a leading slash — is written down explicitly in a dedicated `resolveProductImageSrc` describe block covering all four input shapes (absolute URL, already-rooted path, bare relative path, unusable input).
- `productGallery` on `ProductDisplay` is now a required, defaultless prop; the compiler enforces it and the sole caller (`app/product/[slug]/page.tsx`) needed zero changes.
- `docs/theming.md` no longer lists two coexisting image resolvers as a known limit.

## Decisions Made

- Passed `/placeholder.jpg` as the explicit third argument at every call site rather than relying on `resolveProductImageSrc`'s own default (`/placeholder.svg`), preserving the exact pre-existing fallback filename (per plan's Pitfall 2 finding).
- Left `lib/utils/product-image.ts` completely unmodified — the surviving resolver was adopted as-is, per the plan's explicit prohibition.
- Every render-assertion update touching a bare-path fixture is listed explicitly above (the three `a.jpg`/`b.jpg`/`c.jpg` indexOf checks in the "renders one main image and one thumbnail button per image" test) — no other assertion in either gallery's render suite changed.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → `GET /api/theme` | An unauthenticated, unrated caller reaches a handler that reads admin-owned settings state |
| `/api/theme` response → `app/global-error.tsx` inline styles | Response values would be interpolated directly into `style` attributes on a page rendered without the app's provider tree |
| build machine → prerendered route output | A statically prerendered handler would serve build-time state to every visitor |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08.1-01 | Information Disclosure | `app/api/theme/route.ts` | high | mitigate | Body is built solely from `getThemeTokens(await getActiveTheme())`; the handler never reads or forwards a settings row, a D1 record, or an env value. Enforced by a negative grep on the route source plus a route test asserting the body's key set is exactly `["name","tokens"]`. |
| T-08.1-02 | Tampering | `parseThemeResponse` → crash-page inline styles | high | mitigate | The parser accepts only a manifest theme *name* from the response and resolves token values from the client's own bundled manifest, so a tampered body cannot inject arbitrary values into `style` attributes. Non-manifest names return `null` and the page keeps the default. |
| T-08.1-03 | Information Disclosure | prerendered `/api/theme` | medium | mitigate | `export const dynamic = "force-dynamic"` prevents a build-time prerender freezing the build machine's default theme into the served response. |
| T-08.1-04 | Tampering | shared appearance reader | medium | mitigate | Request-scoped React cache only; no module, isolate, or cross-request cache, so an admin save can never be served stale on a reused isolate. Grep-guarded in `tests/unit/app/layout-switch-contract.test.ts`. |
| T-08.1-05 | Denial of Service | `GET /api/theme` (public, `no-store`) | low | accept | The handler accepts no input and performs one small category-scoped read the root layout already performs on every page render; the response is a fixed-size manifest object. `no-store` is required for correctness. Platform-level rate limiting already fronts public routes. |
| T-08.1-06 | Information Disclosure | dev-server probe evidence in the SUMMARY | medium | mitigate | The probe records only theme names and one token value per body; the development-only admin header token, `.env` values, and full settings responses are never written into any planning record. |

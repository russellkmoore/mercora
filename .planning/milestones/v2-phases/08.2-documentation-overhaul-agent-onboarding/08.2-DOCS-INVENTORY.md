# Docs Inventory

One-line purpose: the keep/merge/retire verdict for every file this phase's documentation
overhaul touches, so plans 02 and 03 execute a work list instead of re-deciding anything.

**Status:** Complete (08.2-01 seeded the first row; 08.2-02 classified the remaining 31).

Mercora is a themeable reference storefront on Cloudflare — Next.js, D1, R2, Workers AI, Stripe
and Clerk — that can render any product catalogue. The shipped sample catalogue is outdoor gear,
and the default look, `volt-dark`, is one of seven presets. Wherever a document describes the
product, that outdoor-gear framing is sample data, not the product's identity, and this phase's
rewrites demote it accordingly.

Two concrete, low-effort gaps keep this phase from a clean pass:

1. **Header convention isn't actually consistent.** Four `docs/` files lack the Status line every comparable file carries, and the phase's automated gate (`docs-lint.mjs`) can't see it because it only checks for a level-1 heading. 2. **The CI gate list is incomplete everywhere it appears.** `check:migrations` genuinely runs in CI on every pull request, but it's absent from `AGENTS.md`, `CONTRIBUTING.md`, and `docs/database-migrations.md` alike.

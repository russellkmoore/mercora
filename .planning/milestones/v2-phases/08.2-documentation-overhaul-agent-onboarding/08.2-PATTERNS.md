## Shared Patterns

### Style contract (D-05) — grep-able verification
**Source:** `08.2-RESEARCH.md` "Style Contract Check Method" section (this phase's own research, no prior repo tool exists for this)
**Apply to:** every remaining `docs/*.md`, `README.md`, `AGENTS.md`
```bash
# stale-link check (run after retirements executed)
for f in admin-dashboard-specification api-architecture ROADMAP o07-gift-cards-plan \
         mobile-improvements-actionable migration-reservations mobile-testing-automation \
         mobile-ux-assessment STRIPE_INTEGRATION; do
  grep -rn "docs/$f" README.md docs/*.md AGENTS.md CLAUDE.md 2>/dev/null && echo "STALE LINK: $f"
done

# broken internal link check
grep -oE '\]\((docs/[A-Za-z0-9_.-]+\.md|[A-Za-z0-9_.-]+\.md)\)' README.md docs/*.md AGENTS.md \
  | sed -E 's/.*\((.*)\)/\1/' | sort -u | while read -r p; do test -f "$p" || echo "BROKEN LINK: $p"; done

# unknown script name check
grep -ohE 'npm run [a-zA-Z:_-]+' README.md docs/*.md AGENTS.md | sort -u | while read -r _ _ script; do
  grep -q "\"$script\":" package.json || echo "UNKNOWN SCRIPT: $script"
done
```

## Planner Assumptions

1. **The generator script is deliberately not committed.** D-07 and the pattern map both describe it as ad hoc; the two sibling images from commit 9df5ed9 were produced the same way and no such script is tracked in git. Reproducibility comes from recording the exact prompt and model in the plan summary, not from a tracked file. Committing a new `scripts/` entry would add lint, typecheck and CI surface for a one-time operation.
2. **The bytes are JPEG even though the file is named `.png`.** Both sibling images produced by this model on 2026-09-07 are JPEG data at 1024x1536 under a `.png` name, and the R2 object for one of them is served as `image/png` today because wrangler infers the type from the extension. This plan keeps that behaviour: the file keeps the `.png` name matching the seeded path, and no explicit content type is passed on upload. The acceptance criterion is therefore about pixel dimensions, not about container format.
3. **The style judgement is the executor's.** D-07 gives no human gate on image choice. The executor generates several candidates, picks the one that best matches the style notes, and shows the chosen image to Russell in the summary afterwards.
